# HAZURE

何も売っていない自動販売機です。ボタンを押すと、言い訳や小さな失敗が落ちてきます。

```bash
npm install
npm run dev
npm run lint
npm test
npm run build
```

音は初期ミュートで、ボタンを押した後だけ鳴ります。WebGL が使えない端末では DOM/CSS 版に切り替わります。

## 検証記録（2026-10-14）

描画エンジンに合わせてWebGL2を初回描画前に判定し、非対応ならDOM版を表示するよう修正した。lint、既存テスト2件、buildを通過。Edgeのヘッドレス検証でWebGL1のみ・WebGLなし・コンテキスト取得例外の3条件を模し、低負荷版の表示、排出操作、初期ミュート、未捕捉例外なしを確認した。実端末での利用者反応は未確認。次は実機で可読性と任意の再操作を観察する。
